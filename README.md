# Neon Rush 3D

Original mobile-first 3D endless runner built with Three.js.

## Controls
- Swipe left/right: change lane
- Swipe up: jump
- Swipe down: slide
- Keyboard fallback: arrows or WASD

## Run
```bash
python3 -m http.server 4173
```
Open `http://localhost:4173`.

Three.js is vendored, so gameplay does not require a CDN at runtime.
